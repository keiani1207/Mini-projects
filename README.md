# Mini-Projects

A collection of small Python scripts and practice tools.

## Projects

### 1. Variable Name Validator (`variable-checker-python.py`)
Checks if a text string can be used as a valid Python variable name.

* **Checks:** Valid syntax and reserved keywords.
* **Run:** `python variable-checker-python.py`

### 2. Bill Tip Calculator (`bill-tip calculator.py`)
Calculates the total tip and splits the final bill amount evenly among multiple people.

* **Checks:** Total bill amount, tip percentage, and number of people splitting.
* **Run:** `python "2.bill-tip calculator.py"`
